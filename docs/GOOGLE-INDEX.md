# Get popularrealtorscbe.com into Google search

The site and sitemap are already live. Google will **not** show it the same day you type the name unless you request indexing.

## Do this once (client Google account)

1. Open https://search.google.com/search-console
2. **Add property** → URL prefix → `https://popularrealtorscbe.com`
3. Verify (easiest: HTML meta tag, or DNS TXT in GoDaddy)
4. Left menu → **Sitemaps** → submit:
   `https://popularrealtorscbe.com/sitemap.xml`
5. Top search bar in Search Console → paste `https://popularrealtorscbe.com` → **Request indexing**
6. Also request indexing for:
   - `https://popularrealtorscbe.com/properties`
   - `https://popularrealtorscbe.com/contact`

## Check status (after 1–7 days)

In Google search try:

```
site:popularrealtorscbe.com
```

If pages appear there, the site is indexed. Ranking for “Popular Realtors Coimbatore” improves over weeks with JustDial + Google Business Profile matching the same name/phone.

## Optional boost

- Create/claim **Google Business Profile** for Popular Realtors CBE, same phone `9943395067`, website `https://popularrealtorscbe.com`
- Keep JustDial listing linked (already on the site)

**Honest note:** Typing only the business name in the address bar always runs a *search*. Appearing in those results needs indexing first — that is a Google step, not a Netlify setting.
